# Big Bang Time Machine

A time-travel game for 9–13 year olds about the origin and evolution of the universe.

**Play it:** https://andrewhmcg.github.io/BigBangTMac/

Fly a time pod through seven eras: the Beginning, Inflation, the Afterglow (cosmic microwave background), the Dark Ages and first stars, Galaxies, Expansion (redshift) and the Big Freeze. Collect facts and evidence, pass a quiz at each time gate, then put the history of the universe in order in the final challenge.

The whole game is the single file `index.html`. Sources are listed in Harvard style on the in-game Sources screen.
